# Dusklight Mods

Personal mods for Dusklight

- [Selected Controller Menu Input](fix-controller-menu/) lets the keyboard and player one's selected controller operate menus, while ignoring other controllers' menu input.
- [Mute Music Button](mute-music-button/) toggles music with F7 by default. The key can be changed in the mod's tab in the Mods window.

Each folder contains its own source, mod manifest, CMake project, and build instructions.
